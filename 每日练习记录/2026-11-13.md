## 批改与参考答案

按题目内容配对，保留作答中从第 1 题跳到第 3 题的编号。答“不知道”计 0 分，空白题附参考答案，未计入已提交部分的得分。

- **第 1 题**　从 Windows CMD 和同一 Compose 网络的应用容器分别连接实验库，地址如何填写？

  **部分正确**。Windows 用 `127.0.0.1:55432` 直连发布的 PostgreSQL 端口。同网应用用 `db:5432`。这两条连接都无需经过 Nginx。
- **第 3 题**　`docker compose exec db psql` 在哪里执行 psql？

  **需修正**。在数据库容器内。本实验未指定主机时默认用 Unix 套接字。
- **第 4 题**　把 CMD 中 `psql -c` 的 SQL 参数用单引号包起来后报语法错误，先如何改？

  **需修正**。用英文双引号包住传给 `-c` 的完整 SQL 或 `\dt`。
- **第 5 题**　切换到复现库时，把 `set DATABASE_URL=...` 和 Alembic 命令直接粘成一行。为什么没有建表？

  **需修正**。Alembic 命令未独立执行。分两行运行，先确认连接目标再执行迁移。
- **第 6 题**　空库和空 `MetaData()` 比较时，生成脚本的 `upgrade()` 里只有 `pass`。这个结果说明什么？

  **部分正确**。空数据库与空 `MetaData()` 都没有表结构可供比较。即使表里没有行，只要表结构有差异，仍可生成迁移。
- **第 7 题**　生成初始迁移时报 `No module named 'models'`，第一步如何判断是导入问题？

  **部分正确**。在课程目录和同一虚拟环境运行 `python -c "import models"`，检查实际导入是否成功。
- **第 8 题**　初始迁移既建项目表又建设备表，为什么项目表应先建？

  **部分正确**。你找对了依赖关系，设备的 `project_id` 是引用 `projects.id` 的外键。
- **第 9 题**　执行初始迁移后看到 `alembic_version` 表，它记录什么？

  **部分正确**。记录数据库当前应用的迁移版本。迁移脚本及其版本链用于查历史。
- **第 10 题**　向设备表插入 `project_id=-1` 的记录失败。用什么查询证明失败记录没有留下？

  **需修正**。用测试设备编码过滤，例如 `SELECT id FROM devices WHERE code = 'fk-test';`，预期零行。
- **第 11 题**　两套实验库初始化后，验收时至少要对照哪些结果？

  **部分正确**。迁移版本、表清单、样例行数及关键记录。实验预期每库 2 个项目、3 台设备。
- **第 12 题**　项目 `flush()` 后拿到了 ID，接着设备写入失败。为什么项目 ID 曾经可用，却查不到项目行？

  **部分正确**。`flush()` 已发出 INSERT，因此 ID 可用。提交前设备写入失败，整个事务回滚，项目行随之撤销。
- **第 13 题**　用 `LEFT JOIN` 查失败项目，返回零行与返回一行且设备编码为 NULL 各说明什么？

  **正确**。零行说明查询不到项目；右侧为 NULL 的一行说明项目存在、没有匹配设备。
- **第 14 题**　分开提交项目和设备后，设备写入失败。沿用同一个项目编码从头重试，会先遇到什么？

  **需修正**。已提交的项目仍在，重新插入时会触发项目编码唯一约束。
- **第 15 题**　接口收到任意 `IntegrityError` 都返回「设备编码重复」，哪里需要改？

  **需修正**。只有识别到 `UniqueViolation` 且约束名为 `uq_devices_project_id_code` 时才返回该 409。
- **第 16 题**　实验中浏览器打开根路径得到 404，打开 `/projects/import` 得到 405，各表明什么？

  **需修正**。根路径没有注册路由；导入路径存在，但浏览器地址栏发的是 GET，接口接收 POST。
- **第 17 题**　命令行怎样发起导入接口所需的请求？

  **未作答 · 参考答案**。用 `curl.exe` 发 `POST http://127.0.0.1:8000/projects/import`，设置 `Content-Type: application/json`。正文示例 `{"project_code":"HTTP-OK","device_codes":["sensor-01","sensor-02"]}`。
- **第 18 题**　接口返回 409 后还要验证什么，才能证明整批确实撤销？

  **未作答 · 参考答案**。收到 409 后、重试前，按失败请求的项目编码查库。`LEFT JOIN` 返回零行，才能确认项目也回滚了；一行且设备编码为 `NULL` 表示项目还在。
- **第 19 题**　SQLAlchemy 的 Engine 与 Session 在本课分别负责什么？

  **正确**。Engine 管理连接，Session 管理 ORM 查询、写入及事务。
- **第 20 题**　告警查询加复合索引后，如何用实测判断它有没有帮到这一条查询？

  **未作答 · 参考答案**。用同一份数据和相同筛选条件，在加索引前后分别运行 `EXPLAIN (ANALYZE, BUFFERS)`，比较扫描方式、排序、耗时和缓冲区读数。
- **第 21 题**　发布新增列的版本后，发现新应用有问题。什么条件下可以只回退应用？

  **需修正**。升级后的数据库仍兼容旧应用，且旧应用的关键读写经冒烟测试通过。
