## 题目

1. 镜像和容器分别是什么？用 nginx 举例。答：image是一个模版，container是使用模版创了一个操作空间。
2. `docker pull nginx` 省略了哪个标签？为什么隔几个月拉取可能得到不同内容？答：省略了版本号，默认会获取最新的
3. 把 nginx 发布到本机 8081 端口并在后台运行，容器名为 `quiz-nginx`。写出命令。答：docker run -d --name quiz-nginx -p 8081:80 nginx
4. `docker ps` 看不到一个刚退出的容器。怎样查看它和退出码？答使用 docker pa -a
5. nginx 监听容器内 80 端口，但发布参数是 `-p 8083:81`。容器显示 `Up`，为什么网页打不开？如何修正？答：因为端口映射错误，改为8083:80.
6. 如何从 Windows 终端验证 `localhost:8081` 返回 HTTP 状态？如何查看容器最近五行日志？答：docker logs --tail 5
7. 容器的主进程只执行 `echo`，输出后正常结束。容器接下来是什么状态？答接下来是stop状态
8. 在运行中的 `nginx:alpine` 容器里打开交互式 shell，应使用什么命令？答：使用docker exec
9. 两个容器来自同一镜像。修改其中一个未挂载的首页，另一个会变化吗？改动写到哪里？答：不会，改动应该写在已挂在的容器
10. 改了未挂载的首页后，对比 `stop` 再 `start` 和删除后用同一镜像重建。分别会看到什么？答：stop会看到已改首页，删除之后看到的是空首页
11. 将空的 Windows 目录绑定挂载到 nginx 的网页根目录，为什么实验中返回 403？答：因为访问到的host 内容
12. 在实验 02 的 bind mount 场景中，从 Windows 修改 `index.html` 后，如何验证新内容已被服务读取？答：直接在浏览器中访问
13. 分别判断 `-v data:/html`、`-v D:\\data:/html`、`-v /html` 的挂载类型。答：卷命名；bind；匿名挂载
14. 新建空命名卷并挂到镜像已有首页的目录时，默认发生什么？答：不知道
15. 命名卷已有自定义首页。重建容器并挂同一个卷，首页来自哪里？答来自之前已经有首页
16. 删除容器后，怎样验证写进 `lab2data` 的文件仍可读？答：重建容器挂载lab2data, 发现原来数据还在
17. 为什么停止容器后，`docker volume rm lab2data` 仍可能提示 `volume is in use`？答：因为肯被其他容器使用
18. 容器需要读取 Windows 网页目录，但应用不应通过这个挂载写入。如何配置？答：命名卷配置
19. 想把一个现有的宿主机文件挂进容器，并在源路径写错时尽早报错，应选 `-v` 还是 `--mount`？为什么？答：写mount
20. Windows 上要一边编辑网页一边预览，同时为 Linux 容器中的数据库保存数据。分别选哪种挂载？说明理由。答：分别选绑定可以直接看到数据改变，再用命名卷实现数据持久化

## 批改与参考答案

- **第 1 题**　镜像和容器分别是什么？
  **部分正确**。模板的理解正确。以 nginx 为例，镜像提供程序和默认配置，容器是从它创建的实例，有独立的可写层
  
- **第 2 题**　`docker pull nginx` 省略了哪个标签？为什么隔几个月拉取可能得到不同内容？
  **部分正确**。默认标签是 `latest`。标签可被重新指向，`latest` 的名字本身不保证镜像版本最新。

  
- **第 3 题**　把 nginx 发布到本机 8081 端口并在后台运行，容器名为 `quiz-nginx`。写出命令。
  **正确**。`docker run -d --name quiz-nginx -p 8081:80 nginx:alpine`。
- **第 4 题**　`docker ps` 看不到一个刚退出的容器。怎样查看它和退出码？

  **部分正确**。命令拼写是 `docker ps -a`，退出码在 `STATUS` 列的 `Exited (...)`。
- **第 5 题**　nginx 监听容器内 80 端口，但发布参数是 `-p 8083:81`。容器显示 `Up`，为什么网页打不开？如何修正？

  **正确**。主进程仍在运行，但流量被转发到容器内 81。用 `-p 8083:80` 重建容器。
- **第 6 题**　如何从 Windows 终端验证 `localhost:8081` 返回 HTTP 状态？如何查看容器最近五行日志？

  **部分正确**。用 `curl.exe -I http://localhost:8081` 查看 HTTP 状态，用 `docker logs --tail 5 quiz-nginx` 看最后五行。
- **第 7 题**　容器的主进程只执行 `echo`，输出后正常结束。容器接下来是什么状态？

  **部分正确**。主进程结束，容器随之退出，通常显示 `Exited (0)`。
- **第 8 题**　在运行中的 `nginx:alpine` 容器里打开交互式 shell，应使用什么命令？

  **部分正确**。`docker exec -it quiz-nginx sh`。
- **第 9 题**　两个容器来自同一镜像。修改其中一个未挂载的首页，另一个会变化吗？改动写到哪里？

  **部分正确**。另一容器不变。题设说首页未挂载，修改落在该容器的可写层。
- **第 10 题**　改了未挂载的首页后，对比 `stop` 再 `start` 和删除后用同一镜像重建。分别会看到什么？

  **部分正确**。停止后再启动，同一容器仍显示修改后的首页。删除重建后显示镜像自带的首页。
- **第 11 题**　将空的 Windows 目录绑定挂载到 nginx 的网页根目录，为什么实验中返回 403？

  **部分正确**。挂载遮蔽了原有首页，目录为空且 nginx 禁止列目录。
- **第 12 题**　在实验 02 的 bind mount 场景中，从 Windows 修改 `index.html` 后，如何验证新内容已被服务读取？

  **正确**。重新请求映射端口，例如 `curl.exe -s http://localhost:8093`，检查响应正文。
- **第 13 题**　分别判断 `-v data:/html`、`-v D:\\data:/html`、`-v /html` 的挂载类型。答：卷命名；bind；匿名挂载

  **正确**。依次是命名卷、绑定挂载、匿名卷。
- **第 14 题**　新建空命名卷并挂到镜像已有首页的目录时，默认发生什么？

  **需修正**。Docker 用目标目录的内容初始化空卷，随后容器通过卷读取首页。
- **第 15 题**　命名卷已有自定义首页。重建容器并挂同一个卷，首页来自哪里？

  **正确**。来自原卷。已有内容的卷不会被镜像默认首页重新初始化。
- **第 16 题**　删除容器后，怎样验证写进 `lab2data` 的文件仍可读？

  **正确**。把 `lab2data` 挂给新容器，再读取目标文件或请求对应网页。
- **第 17 题**　为什么停止容器后，`docker volume rm lab2data` 仍可能提示 `volume is in use`？

  **部分正确**。其他容器可能引用它，刚停止的容器本身也仍然引用它。
- **第 18 题**　容器需要读取 Windows 网页目录，但应用不应通过这个挂载写入。如何配置？

  **需修正**。在绑定挂载参数末尾加 `:ro`，例如 `-v D:\myskills\dockerskill\lab2-data:/usr/share/nginx/html:ro`。
- **第 19 题**　想把一个现有的宿主机文件挂进容器，并在源路径写错时尽早报错，应选 `-v` 还是 `--mount`？为什么？

  **部分正确**。使用 `--mount type=bind`。默认情况下源路径不存在会报错，`-v` 可能在该路径创建目录。
- **第 20 题**　Windows 上要一边编辑网页一边预览，同时为 Linux 容器中的数据库保存数据。分别选哪种挂载？

  **正确**。网页用绑定挂载，便于直接编辑宿主机文件。数据库用命名卷，便于跨容器重建保留数据，并减少 Windows 与 Linux 文件系统之间的读写开销。
