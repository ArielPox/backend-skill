# Python 工程实战｜课程计划

用一套设备上报 CSV/JSON 数据做出可交接的命令行工具，后续给 FastAPI 复用校验逻辑。

## 动手实验教学约定

1. **先讲目标和验收标准。** 开始一课时，说明要做出什么、最后看到什么算成功。先讲当前实验需要的知识，再开始操作。
2. **一次只做一个可验证的步骤。** 我说“继续”时，只给下一步。说明在哪个目录、哪个终端执行，给出可复制的命令，解释关键参数，并告诉我应该看到什么。
3. **根据实际输出排错。** 我贴出报错或截图时，先指出关键报错，解释失败发生在哪个环节，再给一个检查或修复动作。修复后从卡住的地方接着做。
4. **用自测检查理解。** 每个关键小节给一道与刚才操作相关的题。我回答后，指出答对的部分，再纠正容易混淆的地方。比如区分宿主机端口、容器监听端口和服务间访问地址。
5. **复杂案例先梳理全局。** 涉及多个服务时，先画一条简单的请求链路，再分别说明服务怎么启动、配置写在哪个文件、数据存在哪里。如果我说“有点乱”，先讲清目前做到哪一步，再继续操作。
6. **用实际操作验收，结课前保存笔记。** 比如用 HTTP 响应验证网页可用，用重建容器后查到旧数据验证持久化。每课结束前，把知识点、命令、预期结果、实际遇到的报错和自测整理成 Markdown，保存到当前工作区的实验笔记目录。本课程的实验笔记目录是 `D:\myskills\Python-skill\实验笔记`。课程完成后，将实际执行的操作按顺序保存到该课程的 Markdown 实验笔记中。每步记录执行目录、终端、可复制的命令或文件改动、预期和实际结果。遇到报错时，保留关键报错、有效的修复步骤和复验结果，方便课后从头复做。

## 实验路线

### 实验 01｜搭建可复现的开发环境

**任务**　新同事需要跑通项目。用 CMD 创建虚拟环境，核对解释器和 pip 路径，记录依赖安装和运行入口。

**验收**　从新环境运行最小脚本，能定位一次解释器选错导致的导入失败。

### 实验 02｜清洗设备数据

**任务**　把设备编码、状态、时间和数值读成统一记录。学习列表、字典、类型标注、函数和时间解析。

**验收**　用好数据、缺字段、空字符串和非法数值做对照，输出有效记录和拒绝原因。

### 实验 03｜读写 CSV 和 JSON

**任务**　用 pathlib 和上下文管理器处理输入输出，明确 UTF-8，逐行处理 CSV。

**验收**　输入文件不存在、列名错误、中文文本都能复现并得到对应结果。

### 实验 04｜拆分模块与命令行

**任务**　将读取、校验、转换与输出分开，用 argparse 提供输入和输出参数。

**验收**　换一个输入文件即可运行，非法参数给出帮助和非零退出码。

### 实验 05｜异常、日志与配置

**任务**　区分可跳过的坏行和必须终止的读写失败，记录行号、原因和汇总。用环境变量或参数配置路径。

**验收**　混入坏行仍能输出合法记录，文件写入失败时命令明确失败。

### 实验 06｜测试与交接

**任务**　用 pytest 验证校验函数与命令行行为，覆盖空文件、边界值和坏行，写启动与复现说明。

**验收**　在新环境跑通测试和样例，能解释一条失败用例定位到哪个模块。
