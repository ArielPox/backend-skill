## 动手实验教学约定

1. **先讲目标和验收标准。** 开始一课时，说明要做出什么、最后看到什么算成功。先讲当前实验需要的知识，再开始操作。
2. **一次只做一个可验证的步骤。** 我说“继续”时，只给下一步。说明在哪个目录、哪个终端执行，给出可复制的命令，解释关键参数，并告诉我应该看到什么。
3. **根据实际输出排错。** 我贴出报错或截图时，先指出关键报错，解释失败发生在哪个环节，再给一个检查或修复动作。修复后从卡住的地方接着做。
4. **用自测检查理解。** 每个关键小节给一道与刚才操作相关的题。我回答后，指出答对的部分，再纠正容易混淆的地方。比如区分宿主机端口、容器监听端口和服务间访问地址。
5. **复杂案例先梳理全局。** 涉及多个服务时，先画一条简单的请求链路，再分别说明服务怎么启动、配置写在哪个文件、数据存在哪里。如果我说“有点乱”，先讲清目前做到哪一步，再继续操作。
6. **用实际操作验收，结课前保存笔记。** 比如用 HTTP 响应验证网页可用，用重建容器后查到旧数据验证持久化。每课结束前，把知识点、命令、预期结果、实际遇到的报错和自测整理成 Markdown，保存到当前工作区的实验笔记目录。本课程的实验笔记目录是 `D:\myskills\FastAPI-skill\实验笔记`。课程完成后，将实际执行的操作按顺序保存到该课程的 Markdown 实验笔记中。每步记录执行目录、终端、可复制的命令或文件改动、预期和实际结果。遇到报错时，保留关键报错、有效的修复步骤和复验结果，方便课后从头复做。

## 实验路线

### 实验 01｜从页面定位 API

**任务**　从设备详情页的 Network 请求整理字段契约。用 APIRouter、Pydantic 响应模型和模拟数据跑通接口。

**验收**　能从页面追到路由和字段，验证正常请求与不存在的设备。

### 实验 02｜校验、依赖和权限

**任务**　用 Depends 注入调用者和业务依赖，区分参数校验、身份校验与权限判断。

**验收**　分别验证有效请求、非法参数、缺少有效令牌和权限不足时的响应。

### 实验 03｜接入 PostgreSQL

**任务**　复用数据库课程的项目设备模型与迁移。应用通过每请求 Session 访问数据，服务层管理写入事务。

**验收**　空库经 Alembic 可启动。批量导入冲突时返回明确错误，查库确认没有半批数据。

### 实验 04｜分页与告警查询

**任务**　实现设备分页和告警筛选，统一列表与总数口径，约束页大小并检查查询 SQL。

**验收**　用空结果、并列时间和跨项目数据验证返回范围与分页顺序。

### 实验 05｜接口测试和依赖替换

**任务**　用 pytest 和 TestClient 验证 HTTP 契约。用依赖覆盖测试身份，将数据库集成测试指向独立测试库。

**验收**　正常、校验失败、无权限与写入冲突均有可重复测试。

### 实验 06｜部署与排障

**任务**　先梳理客户端 → Nginx → Uvicorn/FastAPI → PostgreSQL。用 Compose 管理服务，独立执行迁移，加入存活与就绪检查。

**验收**　实测正常响应、数据库断开时的就绪状态以及重建后旧数据仍可查，留存日志和恢复步骤。

### 实验 07｜接手综合演练

**任务**　从一条设备或告警需求出发，完成接口变更、测试、迁移核对和发布记录。

**验收**　交付可运行代码、字段映射、测试结果和兼容回退方案，能从错误响应追到日志与数据。
